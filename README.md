# 🎯 Number Guessing Game

A simple **command-line number guessing game** built with Python. The player chooses the highest possible number, and the program generates a random number within that range. The player then keeps guessing until they find the correct number.

## 🎮 How It Works

1. Enter the highest possible number.
2. The program generates a random number between `0` and the selected maximum.
3. Enter your guess.
4. The game tells you whether your guess was **above** or **below** the random number.
5. Keep guessing until you find the correct number.
6. The game displays how many guesses you needed.

## ✨ Features

* Random number generation
* User input
* Higher/lower hints
* Guess counter
* Interactive command-line gameplay

## 🛠️ Technologies Used

* **Python 3**
* **Random module**

## ▶️ How to Run

1. Clone the repository:

```bash
git clone <your-repository-link>
```

2. Open the project folder in your terminal.

3. Run the program:

```bash
python number_guessing_game.py
```

4. Follow the instructions displayed in the terminal.
